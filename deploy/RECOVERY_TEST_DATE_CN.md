# TermRelay 恢复演练记录

这份文件只记录恢复机制的演练结果，不记录任何真实密码、Token、私钥或数据库内容。

每次在测试环境完成灾难恢复演练后，追加一条记录：

```text
日期：YYYY-MM-DD
代码 commit/tag：
镜像 tag/digest：
数据库备份时间：
恢复环境：测试服务器 / 本地隔离环境
结果：PASS / FAIL
问题与修复：
```

正式目标是至少定期验证一次：

1. 新服务器能读取仓库和固定镜像；
2. `.env` 恢复包中的关键值完整；
3. PostgreSQL 备份校验通过；
4. 数据库可以实际恢复；
5. 应用能够启动并通过健康检查；
6. 管理员登录、普通用户数据、关键 API 和 2FA 抽样正常；
7. 新服务器能够重新生成并上传一份加密备份。

只有“真正恢复成功过”的备份体系，才算可依赖的灾备体系。
